# Deploy FleetBuilt Partners (`fleetbuiltpartners.com`)

## What is hosted today

This repository currently carries **two** public surfaces:

| Surface | Location | Host (detected) | Role |
|---|---|---|---|
| Marketing website | `marketing-site/` (static HTML generated by `python3 generate.py`) | **Vercel** project `mobi-marketing-site` (preview URLs in historical blog-automation records) | Public site for fleetbuiltpartners.com |
| Client portal / app | Next.js 15 App Router at repo root (`src/`, `netlify.toml` also present) | **Vercel** project `mobi-portal` (production historically served customer app traffic) | Estimating portal — **not** the FleetBuilt offer |

`netlify.toml` at the repo root configures the Next.js portal (`@netlify/plugin-nextjs`). Live marketing and portal evidence in-repo is Vercel, not Netlify. Treat Vercel as the current host unless you deliberately move the static site.

The FleetBuilt public site is the **static marketing folder**. Build it with:

```bash
cd marketing-site
python3 generate.py
```

There is no Node build step for the marketing pages. Point the Vercel project root at `marketing-site/` (or upload that folder).

Payments: this rebrand **removes live Mobi Stripe / portal checkout links**. Public CTAs go to `contact.html` and `moses@fleetbuiltpartners.com` until a FleetBuilt Stripe account exists.

## Point `fleetbuiltpartners.com` at the marketing site

Do this at **Namecheap** (or whichever registrar holds the domain). **Leave Zoho mail DNS alone.**

Do **not** edit, delete, or overwrite:

- `MX` records (Zoho Mail)
- `TXT` SPF (`v=spf1 … zoho …`)
- Zoho `DKIM` `CNAME`/`TXT` selectors
- `TXT` DMARC (`v=DMARC1 …`)

Add or change **only** web records:

1. In Vercel, open the FleetBuilt marketing project (today: `mobi-marketing-site`, or a new `fleetbuilt-partners` project whose root is `marketing-site/`).
2. Add the domain `fleetbuiltpartners.com` (and `www` if you want it).
3. Vercel will show either:
   - an **A** record for the apex (`76.76.21.21` is the common Vercel anycast target — confirm in the Vercel domain panel), or
   - a **CNAME** for `www` to `cname.vercel-dns.com`.
4. In Namecheap → Advanced DNS:
   - Apex: A record `@` → the Vercel IP from the panel (or ALIAS/ANAME if Namecheap shows that for Vercel).
   - `www`: CNAME → `cname.vercel-dns.com` (or the host Vercel prints).
5. Wait for DNS, then confirm `https://fleetbuiltpartners.com` serves this marketing site and `https://www.fleetbuiltpartners.com` redirects or matches as configured.

If you later host the static site on Netlify instead, use Netlify’s A/CNAME values from that dashboard — still without touching Zoho MX/SPF/DKIM/DMARC.

## After go-live

- Rebuild with `python3 marketing-site/generate.py` whenever `config.py`, `build.py`, or `generate.py` change.
- Connect a FleetBuilt Stripe account before adding any payment button. Until then, keep Contact / email CTAs.
- Do not attach the Next.js estimating portal to `fleetbuiltpartners.com` unless that product is separately re-scoped.
